Not built yet

This tab will let you flash a small demo sketch onto an Arduino over USB — no toolchain, no library installs — then command moves and watch your own servo run them, with the board’s streamed trace drawn against the simulated one.

It is being built in a second pass. What it will need from you:

  • Chrome or Edge on desktop (Web Serial is not available in Firefox or Safari).
  • An ATmega328P board — an Uno, or a Nano of either bootloader vintage.
  • A hobby servo on its own 5 V supply, signal on pin A3.

In the meantime the Simulate tab runs the same compiled library the board will, so the curves there are already the real thing.
